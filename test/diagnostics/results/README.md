# Diagnostic results

Reports generated by the scripts in `test/diagnostics/`. Files are
named with a hardware tag (`<diagnostic-name>_<gpu>_<gpu-model>.md`)
because resource footprints depend on the GPU's register file size,
shared-memory cap, and compute capability.

Each diagnostic script writes to a default unsuffixed name (e.g.
`tier_baseline.md`); rename with the hardware tag once you've confirmed
the data is reference-worthy.

Currently committed reference reports:

- `tier_baseline_sm120_rtx5090.md` — register / spill / smem matrix
  across all emitted kernels × {iiwa14, go2, g1, h1_2} × {fixed,
  floating}. Driven by `test/diagnostics/tier_baseline.py`.
- `glass_vs_pre_glass_sm120_rtx5090.md` — 2026-05 register-diff
  comparison between HEAD GLASS and the pre-GLASS reference at commit
  `d2c0d18`. Driven by `test/diagnostics/glass_vs_pre_glass_ptxas.py`.

Reports without a hardware tag (e.g. `tier_baseline.md`) are the
default output location and may be overwritten by subsequent runs.
Rename to add the hardware tag before committing.
